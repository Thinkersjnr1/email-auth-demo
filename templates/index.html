Protocol Guide
SPF — Checks the sending server IP against the domain's authorised sender list.
DKIM — Verifies an RSA cryptographic signature tied to the sending domain.
DMARC — Enforces alignment policy across SPF & DKIM; decides reject / quarantine / none.
